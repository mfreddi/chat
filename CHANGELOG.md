# Changelog

Список изменений по версиям. Публикуется вместе с релизом в mfreddi/chat и показывается в приложении при обновлении - каждый пользователь видит всё, что добавилось с его текущей версии, даже если пропустил несколько релизов.

## 0.5.8

- Если интерфейс не загрузился или завис (белый экран) — теперь всплывает системное окно с кнопками «Перезагрузить» / «Закрыть», а не остаёшься в мёртвом окне без управления. При запуске подчищаются зависшие вспомогательные процессы от прошлой сессии; занятый порт больше не роняет старт
- Телефон-пульт: вкладка **«Чат»** — объединённая лента Twitch / VK Live / Kick прямо на телефоне (иконки площадок, эмоуты, цвета ников, бейджи, удаление модератором). Read-only. Плюс кнопки «на весь экран» и фиксация ориентации — телефон на подставке как второй монитор. Пульт теперь открывается, даже если микшер и OBS выключены, — достаточно подключённой площадки
- Управление OBS (**beta**, Настройки → OBS): переключение сцен из приложения и с телефон-пульта. Подключается к встроенному obs-websocket (OBS 28+ — включить в Сервис → Настройки сервера WebSocket). Выбираешь, какие сцены и в каком порядке показывать на пульте
- Новый раздел «Пульт» (**beta**): микшер громкости приложений для стрима без железного пульта. Выбираешь приложения из списка и крутишь громкость игры, Discord, музыки, браузера по отдельности; мьют; пресеты микса и кнопка «Паника» (заглушить всё, повторное нажатие возвращает). Видит приложения на всех устройствах вывода, включая виртуальные (Wave Link и т.п.). Плюс **телефон-пульт**: открываешь ссылку по QR-коду на телефоне в той же Wi-Fi сети — фейдеры и пресеты под пальцем, «добавить на главный экран» открывает без панелей. Данные не выходят за пределы локальной сети. Только Windows (на macOS нет системного API громкости приложений). Аудио-конфигурации у всех разные — если что-то не работает, напиши в Telegram. Настройки → Пульт

## 0.5.7

- Новый оверлей «CS2 — статистика стрима» (**beta, ещё не обкатан на живых матчах** — если что-то считается криво, напишите): сводка за текущий эфир — счёт по матчам и винрейт, серия W/L, суммарный K/D/A и HS%, раунды отдельно за CT и T, мультикиллы (3K/4K/ACE). Не дублирует то, что и так видно в интерфейсе игры (HP, деньги, оружие). Данные — из Game State Integration, официального механизма Valve: кнопка «Настроить CS2» сама кладёт конфиг в папку игры. Новая сессия стартует автоматически после долгой паузы или по кнопке. Настройки → Оверлеи для OBS → CS2

## 0.5.6

- Награды (Настройки → Награды): создание и управление наградами за баллы канала теперь для Twitch, VK Live и Kick, а не только для VK. Одну награду можно создать сразу на нескольких платформах — она добавится/изменится/удалится на всех выбранных за один раз. Фильтр по платформам, включение/выключение, редактирование, удаление, тумблер «пропускать очередь на модерацию». Существующие награды VK подхватываются автоматически. Управлять можно только наградами, созданными через mFchat (ограничение Twitch/Kick); для Twitch нужен статус Affiliate/Partner и переподключение (добавлено разрешение на управление наградами)
- Twitch: гифки из чата (новый тип сообщений) теперь показываются картинкой — и в окне, и в оверлее для OBS (в оверлее размер ограничен, в бегущей строке — до высоты строки). Озвучка их не зачитывает
- Новый оверлей «Первое сообщение» (Настройки → Оверлеи для OBS): когда зритель пишет в чат первый раз за стрим — плашка в OBS + звук. Кастомизация: текст, позиция, цвета, аватар, анимация, картинка на плашке (gif/webp/png). Звук по умолчанию + профили (своя плашка и звук), которые назначаются на конкретные ники или роли (модератор / VIP / подписчик). Фон плашки — цветом, градиентом или картинкой. Защита от наплыва: при рейде — одна сводная плашка «+N новых зрителей» вместо десятков, пауза между плашками, кап очереди; ники со своим звуком показываются всегда. Считается по всем площадкам, сброс при перезапуске приложения

## 0.5.5

- Синтез речи: третий движок — «Алиса (Яндекс)». Нейросетевые голоса Алисы, Оксаны и Захара, аккаунт и ключ не нужны. Неофициальный — провайдер может отключить его в любой момент; регулятор скорости/тона на него не влияет
- Синтез речи: если озвучить сообщение не удалось (нет сети, сервис недоступен), в чат приходит уведомление — стример видит, что сообщение осталось незачитанным, а не гадает почему тихо

## 0.5.4

- Оверлей чата для OBS больше не остаётся пустым после перезагрузки страницы (смена сцены, обновление источника) — при переподключении приложение отдаёт ему последние сообщения, и лента сразу восстанавливается
- В оверлее чата у каждого сообщения теперь виден значок платформы — те же иконки, что и в самом приложении (заодно обновил устаревший логотип VK Play)
- Новый раздел «Фильтр чата» (Настройки → Чат): список аккаунтов, чьи сообщения не показываются нигде — ни в окне, ни в оверлее, ни в озвучке. Предзаполнен популярными ботами (Nightbot, StreamElements и др.), список редактируется. Плюс отдельный тумблер «прятать команды» — сообщения зрителей на `!`/`/` не мелькают в чате, но сами команды (`!jump`, `!race`, колесо) при этом работают
- Забег и Прыжки больше не пишут «!jump»/«!race» в чат от твоего имени — стартовая заявка (чтобы раунд не был пустым) засчитывается локально. Меньше мусора в чате, не упирается в антифлуд VK Play. Поля «код эмоута для теста» убраны за ненадобностью
- Чат держит в памяти последние ~400 сообщений вместо всей истории за эфир — на долгих стримах с быстрым чатом приложение не разрастается по памяти и не начинает подтормаживать

## 0.5.3

- Колесо фортуны (Настройки → вкладка «Колесо»): оверлей для OBS с прокрутом по кнопке. Сегменты вручную или из награды канала — зрители за баллы предлагают варианты, повторный текст поднимает вес (шанс). Несколько колёс с разными списками/режимами/наградами (переключение в настройках), общий вид на всех. Режимы «на победителя» и «на выбывание». Настройка указателя (пресеты или своя картинка), маскота в центре, цветов, обода, текста, звуков (свои или синтетические), конфетти. Общий выключатель «Колесо на экране» — не нужно скрывать сцену в OBS
- Настройки: разделы теперь в боковом меню с группами (Подключение / Чат / Оверлеи для OBS) вместо ряда вкладок — не нужно скроллить вбок. «Чат для OBS» и «Сейчас играет» разнесены на отдельные пункты
- О новой версии теперь можно узнать, не перезапуская приложение: mFchat проверяет обновления не только при старте, но и раз в несколько часов, и показывает ненавязчивую всплывашку в углу + бейдж рядом с номером версии в статус-баре. Полный список изменений — по клику
- Синтез речи: список системных голосов больше не бывает пустым при открытии настроек (ждёт, пока ОС их отдаст)
- Меньше зависших фоновых процессов, если приложение закрыть не кнопкой (Cmd+Q, из дока, из терминала)

## 0.5.0

- Турнир (Настройки → вкладка «Турнир»): проведение турниров с оверлеями для OBS. Форматы — одиночная сетка, круговой (по турам), очковый (FFA: все против всех, очки за игры по местам), «вручную» (свои матчи, перетаскивание порядка). Участники списком, генерация сетки, счёт матчей кнопками `−/+` с автопобедой по BO (отдельный BO финала), продвижение победителей, выбор «живого» матча. Логотипы участников (загрузка картинкой). Три отдельных оверлея (ссылки и тумблеры видимости там же): «Счёт матча» — компактная плашка сверху/снизу, «Сетка» и «Таблица» — на сцену-перерыв, фон только под контентом. Кастомизация: акцентный цвет (свотчи или свой hex), позиция, размер, логотипы, заголовок, анимация счёта. Кнопка «Тест оверлеев». Всё меняется в настройках и сразу применяется
- Настройки теперь открываются в отдельном окне (раньше — панель поверх чата): удобнее при большом числе настроек, можно вынести на второй монитор, окно запоминает размер и позицию. Вкладки снова с названиями, «Награды» — последней. Изменения в окне настроек (платформы, озвучка, события, эффекты) сразу применяются в окне чата без перезапуска
- Статус-бар: суммарный счётчик зрителей по всем платформам переехал в правый угол
- Эмоуты 7TV/BTTV: глобальный набор теперь встроен в приложение и подхватывается, если API 7tv.io / betterttv.net недоступны (актуально для РФ); канальные наборы по-прежнему тянутся онлайн
- Синтез речи: при очереди из нескольких озвучек следующая готовится заранее, пока играет текущая — меньше пауз между наградами (движок Edge TTS)
- Гороскоп: озвучка и сообщение в чате теперь начинаются с названия знака зодиака, а не сразу с текста прогноза

## 0.4.6

- Kick (Настройки → Платформы → строка Kick, кнопка авторизации): полноценное подключение. В мультичат приходят сообщения, эмоуты, бейджи, фолловы, подписки, подарки и выкупы наград — с никами и мгновенно; в статус-баре — счётчик зрителей и фильтр платформы. Объявления (забег/прыжки/итоги) уходят и в чат Kick. Награды Kick можно назначать на эффекты «Забег» и «Прыжки» — выкуп запускает раунд (mFchat сам принимает выкуп)
- Новый эффект «Забег» (Настройки → Эффекты): выкуп награды открывает приём заявок, зрители едут командой `!race` (одна на человека, с эмоутом из сообщения). Гонка рисуется узкой полосой снизу в отдельном оверлее для OBS и не перекрывает картинку — можно жать награду хоть посреди игры. Настройки: время приёма заявок, длительность забега, «хаотичность» (рывки и сюрпризы). По окончании в чат приходит топ-3. Кнопка «Тест» и ссылка для OBS — там же
- Синтез речи: в чат приходит уведомление, если озвучка сообщения не удалась (раньше падала молча)
- Чат для OBS: на оверлей больше не попадают служебные строки (объявления раунда, алерты фолл/саб/рейд) — только реальные сообщения зрителей; удалённые модератором сообщения теперь пропадают и с оверлея

## 0.4.2

- Новый эффект «Прыжки»: выкуп настроенной награды запускает раунд, в чат приходит объявление, а зрители прыгают с парашютом на мишень в отдельном оверлее для OBS, написав в чат `!jump` (если в сообщении есть эмоут/смайл - зритель прыгнет с ним). По окончании раунда в чат приходит топ прыжков. Три темы мишени - платформа, облако, котёл (или случайный выбор при каждом раунде) - с готовой рисованной графикой
