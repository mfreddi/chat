# Changelog

Список изменений по версиям. Публикуется вместе с релизом в mfreddi/chat и показывается в приложении при обновлении - каждый пользователь видит всё, что добавилось с его текущей версии, даже если пропустил несколько релизов.

## 0.4.2

- Новый эффект «Прыжки»: выкуп настроенной награды запускает раунд, в чат приходит объявление, а зрители прыгают с парашютом на мишень в отдельном оверлее для OBS, написав в чат `!jump` (если в сообщении есть эмоут/смайл - зритель прыгнет с ним). По окончании раунда в чат приходит топ прыжков. Три темы мишени - платформа, облако, котёл (или случайный выбор при каждом раунде) - с готовой рисованной графикой
- Настройки эффекта: длительность раунда, задержка между прыжками, тема мишени, отдельные тестовые коды эмоута/смайла для Twitch и VK Play

## 0.4.0

- Добавлен чат для OBS (Настройки → Чат для OBS): готовая ссылка на прозрачную страницу с чатом для Browser Source, два режима - обычный список и бегущая строка (для узкой полосы внизу экрана) со своей скоростью прокрутки, кнопка "Тест" для проверки анимации без ожидания реальных сообщений

## 0.3.1

- Уменьшено количество служебных логов VK Play в режиме отладки - остались только реально полезные (неизвестные события), убраны уже изученные и хорошо работающие

## 0.3.0

- Добавлен Edge TTS - бесплатный нейросетевой голос как альтернатива роботизированному системному (Настройки → Синтез речи). Озвучка теперь работает через очередь (сообщения не перебивают друг друга), появилась кнопка "прервать" и индикатор статуса в шапке
- Twitch: добавлены объявления о фоллоу, подписках и битах прямо в чате, с отдельными тумблерами показа каждого типа (Настройки → События). ⚠️ Требует переподключить Twitch, чтобы выдать новые разрешения
- VK Play: чат-события переведены на актуальную версию протокола (стабильнее переподключение), исправлен дубль сообщений, добавлены объявления опросов (`/poll`) и старта/окончания стрима в чат. Команды `/followalert on` и `/subalert on` теперь включаются автоматически при подключении VK Play
- Исправлено: гороскоп по команде всегда отвечал "не найден" из-за пары багов в парсинге ответа VK
- Исправлено: некоторые уведомления об ошибках показывались дважды поверх друг друга
